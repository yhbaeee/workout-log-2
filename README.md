# 오늘의 운동기록

AI가 추천한 운동을 날짜별로 기록하는 한국어 웹앱입니다. 부위·장비·난이도·개수를 고르면 AI가 운동을 추천하고, 추천 운동이 '기록하기'에 등록되어 세트별 중량·반복 횟수를 기록한 뒤 '기록 보기'에서 확인합니다. 교육용 개인 미니 프로젝트이며 로그인·외부 DB 없이 동작합니다. AI 추천은 OpenAI API를 쓰며 키가 있을 때만 켜집니다(로컬은 `.env`, 배포는 Streamlit Secrets). 키가 없는 환경에서는 기본 운동 26개 목록으로 기록합니다.

## 핵심 기능
- 기본 운동 26개(어깨 7·가슴 7·등 6·하체 6): 운동별 중량 입력 기준과 한조바디 자세 영상. AI 추천이 켜져 있으면 추천 결과로, 꺼져 있으면 부위별 목록으로 기록
- 운동별 중량 입력 기준 표시(덤벨/바벨/머신/맨몸), 세트별 중량·횟수·메모 기록, 세트 추가·삭제
- 기록 보기: 날짜별 조회, 세트 수정·삭제(삭제 전 확인)
- 백업·복원: JSON 다운로드/업로드(복원은 기존 기록 전체 교체), 전체 초기화, 가상 데모 기록
- 운동별 자세 영상(한조바디 채널). 영상은 토글을 켰을 때만 불러오며 '유튜브에서 열기' 버튼 제공
- AI 운동 추천(선택): 부위·장비·난이도·개수·추가 요청 → 추천 운동이 기록하기에 자동 등록(탭 자동 이동) → 세트 기록 → 기록 보기

## 로컬 설치 및 실행
```
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # (선택) AI 기능을 쓸 때만. macOS/Linux: cp .env.example .env
streamlit run app.py
```
로컬에서는 `.env`의 `OPENAI_API_KEY`를, Streamlit 배포에서는 앱 설정의 Secrets에 `OPENAI_API_KEY = "키"`를 넣으면 AI 운동 추천 탭이 켜집니다. 키가 없으면 그 탭만 '사용 불가'로 표시되고, 기록하기에서 기본 운동 목록으로 기록할 수 있습니다.

## AI 운동 추천 (선택 기능)
- **흐름:** 'AI 운동 추천' 탭(첫 번째 탭)에서 부위(어깨/가슴/등/하체), 장비(맨몸/덤벨/바벨/머신/케이블/상관없음), 난이도(초보/중급/상관없음), 개수(3~6), 추가 요청(선택, 300자)을 고르고 추천받습니다(세션당 10회). 추천받는 중과 후에 '생성 과정'(조건 확인 → 보낼 정보 → AI 호출·응답 시간 → 응답 검증 결과 → 등록된 운동 목록)을 단계별로 보여 주고, 추천이 끝나면 '기록하기' 탭으로 자동 이동해 추천 운동 전부가 등록됩니다. 저장한 세트는 '기록 보기'에서 확인합니다.
- **표시:** 기록하기 탭의 '이번 추천 운동' 카드에 `[기본 운동]`/`[AI 생성]` 라벨, 중량 입력 기준, 영상 영역을 보여 줍니다. AI 생성 운동은 설명 1~2문장, 일반 주의사항, 검색 키워드를 함께 보여 줍니다. 화면에 '의료·재활·부상 치료 조언이 아니며 개인 맞춤 처방이 아님'을 표시합니다.
- **영상·링크:** 추천 운동 이름이 기본 운동 26개와 같으면 기본 운동으로 연결해 확인된 한조바디 영상을 그대로 씁니다. 새 AI 운동은 확인된 영상이 없으므로 앱이 검색 키워드로 만든 '한조바디 채널에서 검색' 링크(채널 검색 페이지)만 제공합니다. 모델이 URL·영상 ID·길이·타임스탬프를 만들지 않도록 응답 형식(JSON 스키마)에 해당 필드를 두지 않고 텍스트 속 링크도 지웁니다. 세트·횟수·중량 같은 수치 처방 문장도 지웁니다. 앱 실행 중 유튜브 검색·조회는 하지 않습니다.
- **저장:** 추천 결과는 세션 임시이며 전부 기록하기에 등록됩니다(필요 없는 운동은 '목록에서 빼기'). 다시 추천받으면 목록이 새로 바뀝니다. '내 운동 목록'(최대 20개)에 저장한 AI 운동은 다시 추천받아도 남고 'AI 운동 추천' 탭에서 '기록하기에 추가'로 재사용하며 백업에 포함됩니다. 저장하지 않았고 기록도 없는 AI 운동은 정리됩니다. 기록이 남은 AI 운동은 삭제할 수 없고, 기본 운동 26개는 삭제 대상이 아닙니다. `data/exercises.json`에는 쓰지 않습니다.
- **보내는 정보:** 부위·장비·난이도·개수·추가 요청과 해당 부위의 기본 운동명·저장된 AI 운동명(영상 연결·중복 방지용)만 보냅니다. 저장한 기록·중량·메모는 보내지 않습니다. 추가 요청란에 개인정보·사내 정보를 넣지 마세요. 응답은 OpenAI에 저장하지 않도록(`store=False`) 요청합니다.
- **키와 모델:** 키는 프로젝트 루트의 `.env`(실행 위치와 무관)를 먼저 보고, 없으면 환경 변수 `OPENAI_API_KEY`를 씁니다. Streamlit Community Cloud는 Secrets의 최상위 값을 환경 변수로 전달합니다. `OPENAI_MODEL`이 비어 있으면 `ai_client.py`의 `DEFAULT_MODEL`(`gpt-6-astra`)을 씁니다. 키는 화면·로그·오류 메시지·저장소에 나오지 않습니다.
- **오류:** 키 없음, 인증 실패, 권한 없음, 모델 없음, 사용량 한도, 시간 초과(45초, 재시도 1회), 네트워크, 서버 오류, 응답 형식 오류를 구분해 안내합니다.
- **제외:** 영상 자동 검색·URL 검증, 자세 이미지 생성, 중량 처방, 효과 예측, 기록 기반 개인화 추천, 모델 선택 UI, 스트리밍.

## 영상 출처와 확인 범위
- 출처: 유튜브 '한조바디' 채널 영상 26개 (상세는 `docs/video_research.md`)
- 확인한 것: 영상 제목, 채널명, URL, video ID, 영상 길이
- 확인하지 못한 것: 영상 시청·자막·설명, 운동 설명 시작 시각(전부 미확인, 처음부터 재생)
- '초보자들을 위한 몸짱 공식'이라는 제목의 시리즈는 확인하지 못해, 같은 채널의 '초보자도 쉽게 배워봅시다'·'몸짱공식' 표기 영상과 운동명이 제목에 있는 설명 영상을 사용했습니다.
- 영상 정보는 개발 단계에서 조사해 `data/exercises.json`에 저장했고, 앱은 실행 중 유튜브를 검색·크롤링하지 않습니다.

## 기록 저장 방식과 한계
- 기록은 `st.session_state`(현재 브라우저 세션)에만 저장됩니다. 새로고침으로 세션이 새로 시작되거나 서버가 재시작되면 사라질 수 있습니다.
- 서버 파일이나 외부 DB에 저장하지 않으므로, 사용 후 **JSON 백업을 다운로드**해 두세요.
- 사용자 간 기록은 공유되지 않습니다(전역 객체·공용 캐시 미사용).
- 입력 범위: 중량 0~1000kg, 반복 횟수 1~1000회 정수, 메모 200자 이내, 복원 파일 5MB 이하(오입력 방지 목적).

## JSON 백업·복원
1. '백업·복원' 탭 → 'JSON 백업 다운로드'
2. 복원: 같은 탭에서 백업 파일 업로드 → 기존 기록이 있으면 교체 확인 → 완료
3. 형식이 잘못된 파일이면 기존 기록은 그대로 유지되고 오류가 표시됩니다.
4. 백업 형식 버전 2부터 AI 운동 정의(내 운동 목록·기록에 쓰인 것)가 함께 저장됩니다. 버전 1 백업도 그대로 복원됩니다.

## 미구현 기능
로그인·계정, 외부 DB, 통계/그래프, 기록 기반 운동 추천, 영상별 설명 시작 시각, 1RM·볼륨·칼로리 계산, 개인별 중량 처방, 새 AI 운동의 확인된 영상(웹 검색·영상 존재 확인).
